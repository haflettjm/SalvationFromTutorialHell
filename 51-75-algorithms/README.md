### Skills introduced in this tier:
- Core data structures (hash maps, trees, graphs, heaps, tries)
- Algorithm analysis and Big-O reasoning
- Systems internals (containers, memory, scheduling, garbage collection)
- Building tools from scratch (database, HTTP server, shell, regex)
- Distributed systems fundamentals (consensus, consistent hashing)
- Low-level networking (TCP implementation)
