### What comes after the basics?
The first 25 projects focus on building a strong foundation in Go, CLI tooling, HTTP, networking, and database fundamentals. Once these are complete, the following skills will be introduced in projects 26-100:

- Advanced testing strategies (integration, e2e, benchmarking)
- Concurrency patterns (goroutines, channels, mutexes)
- Message queues & event-driven architecture (RabbitMQ, Kafka, NATS)
- Caching (Redis)
- Infrastructure as Code (Terraform)
- Observability & distributed tracing (OpenTelemetry)
- gRPC & microservices communication
- OAuth2, RBAC, service-to-service auth
- Data pipelines & ETL
- Incident response, runbooks, and postmortems
