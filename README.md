# SalvationFromTutorialHell
100 Projects to fully understand all of software engineering. Built using QDD and TDD.

### Methodology:
- **QDD (Question Driven Development)**: Drive learning by asking questions first, then building to answer them. No blindly following tutorials.
- **TDD (Test Driven Development)**: Write tests before writing code. Fail, pass, refactor, repeat.

### The Why?
    I have been programming on and off for years and failed to make any personal projects or dive into anything I have found interesting. This ends today. I know ~10 years?!! It's a long story I wasn't always tech focused in my career.

### The Language:
    I am starting this endeavor to help teach me goLang. I have been reading a few books about applying goLang into a DevOps workflow and wish to transition that to be more functional across a team.

## Project Layout

### `01-25-basics/`: Basics
Foundational projects to build core programming skills and fundamentals. CLI tools, HTTP servers, databases, networking.

### `26-50-applied/`: Applied Engineering
Intermediate projects that combine multiple concepts and introduce production-grade patterns. Message queues, caching, gRPC, IaC, CI/CD.

### `51-75-algorithms/`: Algorithms & Internals
Deep dives into data structures, algorithms, and building things from scratch. Containers, database engines, consensus, compilers.

### `76-100-advanced-systems/` — Advanced Systems
AI, full-stack applications, systems programming, and computing at scale. The capstone tier.

**Notable projects planned:**
- **RAG + Distributed Agent System**: AI with retrieval-augmented generation and distributed agent orchestration
- **Video Streaming Service**: Video encoding, chunking, and streaming over the network
- **Discord Bot**: Feature-rich bot with commands, integrations, and persistence
- **Large-Scale Database Project** : Heavy data, complex queries, optimization, and scaling
- **Kubernetes Operator**: Custom CRD and controller for app lifecycle on K8s
